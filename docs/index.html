03别的攻略不会给你的东西

这十条是这个 Skill 和「随手生成一篇攻略」之间的实际差距。

01时间轴写到钟点

不是「第二天：然乌→林芝」，而是「07:30 出发 → 08:15 波密检查站 → 09:40 然乌湖观景台停留 40min → 11:20 充电站充至 90%」。

02闭馆日对撞

布宫每周一闭馆且不售当日票、亚丁旺季限流 15000/日。Skill 会算出「哪一天几点必须动手抢票」并顶在页面最前面。

03纯电写算式不写标称

470 × 0.9 健康度 × 0.7 高速 × 0.92 高原 = 272km/趟，据此排 12 次充电，每个必充点写清「第几高速 · 第几公里 · 到站剩多少%」。

04返程不走回头路

24 天要塞下不走回头路，唯一解是返程改走 G4218 拉萨→昌都→江达→德格→甘孜约 2000km，而不是 318 折返。

05长途日主动拆分

林芝→拉萨 435km/6.5h 拆成两天，因为中途必须充电，硬开会把疲劳驾驶拉到 7.5 小时以上。

06预算精确到人均

电费 946kWh×1.5、住宿 23 晚×2 间×260 → 4 人合计 58,584 元 / 人均 14,646 元。Hero 区、正文小计、页脚三处强制对齐。

07左侧二级目录

10 个一级 + 31 个二级，滚动跟随高亮 + 进度条。宽屏自动展开，窄屏回落到顶部目录盒。

08点图看的是同一张原图

放大后展示的是同一张原图，不是另开一张压缩版。全部 36 张逐张点开验证 src 完全一致。

09每张图能溯源

配原笔记链接（带 xsec_token，能直接打开）+ 搜同款兜底 + 赞/藏/分享数据。索引表 36 行与用图数严格一致。

10离线双击可用

src="http" 为 0，图片全 base64 内嵌，地图是手绘 SVG。微信里转发、飞机上打开都不怕。

04怎么用这个 Skill

安装 → 登录 → 说一句话 → 回答问题 → 确认总览 → 等产物。

  1. 安装

    git clone https://github.com/liuxd-hpy/travel-guide-page.git \
  ~/.config/opencode/skills/travel-guide-page

    Windows 是 %USERPROFILE%\.config\opencode\skills\travel-guide-page， Claude Code 则是 ~/.claude/skills/travel-guide-page。 目录名必须叫 travel-guide-page，装完重启。

  2. 说一句话

    做一份川藏线 24 天自驾攻略，7 月 12 号出发，纯电车 4 个人

  3. 回答 2–3 组问题

    助手会一次问完，不会挤牙膏：行程骨架（日期与时间）、交通与预算（人数 / 车型 / 纯电必须问「高速按几折算」 / 住宿档位）、内容与交付（必去景点 / 节奏 / 忌口 / 要不要机位章 / 交付形态 / 图片来源要不要小红书实拍）。

    纯电一定要回答「高速按几折算」

    这个数字决定充电次数，进而改写时间轴、路况提醒和电费预算。说不清就按 7 折算， 再乘电池健康度和高原衰减。

    如果你说「图片来源不要小红书 / 我自己提供图」，整个流程完全不需要登录。

  4. 看《行程总览表》

    助手会先核实票价、闭馆日、预约窗口，给一屏总览表，含「哪一天几点必须动手抢票」的醒目提示框。 到这一步为止，全程不需要登录小红书。

  5. 需要扫码时，助手会主动弹窗（唯一需要你动手的一步）

    只有真正要抓图的那一刻，助手才自检登录态：

    📱
    请先登录小红书
    用手机 App 扫描下方二维码完成登录
    为什么必须要登录：
    未登录时小红书的搜索结果是空的，
    而且不报错。
    ✅ 我已登录，继续

    已登录就直接开抓，不打扰你；未登录则自动打开小红书并弹出上面这个遮罩。

    你扫码 → 手机上点确认 → 再点「我已登录，继续」。 助手会等你点，不会自己去猜你登录好了没有；点完它再校验一次登录态，成功才继续。

    登录态存在浏览器 profile 里，整个任务只需登录一次。另外：约 70 次页面访问后会跳 「安全验证」captcha，需人工过一下，这是平台限流不是 Skill 出错。

  6. 等产物

    抓图和选图最耗时（要人眼看 contact sheet 挑图）。跑完你会得到两个 HTML 文件，直接转发即可。
