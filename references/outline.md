# 01–10 章内容契约

页面骨架用 `assets/template-desktop.html` / `assets/template-mobile.html`，本章表说明每章**必须写什么**、以及可用的 CSS 类。
章节编号必须连续（01–10），`<section id="s1">…<section id="s10">` 与目录锚点一一对应。
电脑版**必须**再跑一次 `scripts/sidebar.py` 生成左侧二级目录（规范见文末「左侧二级目录规范」）；手机版无侧栏，跳过。

## 类词汇（模板已内置，直接用）

| 类 | 用途 |
|---|---|
| `.cards` + `.card` + `.tag(.r/.g)` | 卡片网格（景点、贴士、预算项） |
| `.card .price` | 价格数字（红色加粗） |
| `.day` + `.day-h`(`.d`/`.km`) + `.tl` + `.tl li` + `<time>` | 逐日行程卡 + 时间轴（`time` 列放钟点） |
| `.tip` / `.tip.warn` / `.tip.ok` | 提示框（黄=注意 / 红=警告 / 绿=好消息） |
| `.ph` > `img` + `figcaption` | 图片块（**不裁剪**，点图看大图），`.zoom` 是 hover 角标 |
| `.g2` / `.g3` / `.g4` | 图片网格（手机版 <820px 自动单列） |
| `.g5` | 五列图片网格（机位章一排 5 张用；<900px 变 2 列，<560px 变 1 列） |
| `.mapbox` + 内联 `<svg>` + `.mapnote` | 手绘路线图 / 城市点位图（零外链、零体积） |
| `.tw` > `table.odd` | 可横滑表格（门票、预约、充电、预算） |
| `.gal` + `.gi` | 图库（JS 自动克隆正文原图，**不要手写**） |
| `#lb` | 大图层（JS 已写好，图片 `src` 为空是正常的） |
| `<nav id="side">` + `#sidefill` + `a.on` | 左侧二级目录（由 `scripts/sidebar.py` 注入，**不要手写**） |
| `data-toc` 属性 | 声明「这个元素要进侧栏二级目录」（`data-toc="文案"` 或空 `data-toc` 取标题文字） |

图片 token：`@@IMG:<key>@@`（注入 base64）、链接 token：`@@U:<key>@@`（注入带 token 的笔记链接）、索引表：`@@NOTES@@`（注入互动数据表）。
`<key>` 建议用两位数字（`01`、`02`…），与 `cands.json` 的 `i` 字段一致。

## 章节清单

### 01 路线总览 / 出发与路线总览
- 卡片逐段写：**里程或车次 + 时长 + 路线 + 当晚住宿地**
- 自驾：补高速免费/限行政策结论（"往返省约 X 元"）
- 公共交通：补枢纽衔接、建议提前几天买票
- **内联 SVG 路线图**（自驾必做，见下）
- 配图 1–2 张（山路/天际线/车窗视角），放 `.g2`

### 02 逐日行程 · 具体时间点（**最核心**）
- 每天一张 `.day`：`D0 10/1 四｜赣州 → 吉安｜220km 约2.5h`
- `.tl` 里每行 = 一个钟点 + 具体动作：`06:30 满电出发，G45 → G60`
- 长途日必写：换手规则、充电/加油点、限速提醒、预计到店时间
- 到达日必写：入住 → 晚饭 → 当晚亮点（夜景/演出/夜市）
- 每天配 1–3 张当日实拍图
- **首日若当天出发**：从出发时刻起算，不要按"Day1 早上"写

### 03 必去景点 · 门票与看点
- 4 必去 + 2 备选，每张卡：**票价 / 折扣 / 看点 / 建议用时 / 加购项 / 一句避坑**
- 门票按成人价写，团队票另计
- 备选要写"什么时候换上去"（例：体力好可把备选换成狮子关）

### 04 打卡机位 · 拍照姿势
- **内联 SVG 城市点位图**（见下），放在本章最前面
- 4 个机位，每个写**站在哪 / 怎么站 / 最佳光线时段**
- **每个机位配 3–5 张实拍，展示不同姿势/构图**，不要一个机位只给 1 张
- 3 组拍照姿势（每组 3 条），按场景分（栈道 / 船 / 夜景）
- 人数多时写"轮流当模特"的组织方式

### 05 预约与开放时间（**时效性最强**）
- 表格：景点 / 票价 / 怎么约（官方渠道、提前几天）/ 开放时间 / 入园限制
- 顶部放醒目提醒：**什么时候抢票、抢不到怎么调**
- 附现场实拍图（价格公示牌、演出时间表、排队牌）

### 06 自驾锦囊（自驾）/ 市内与景区交通（公共交通）
- **自驾版**：隧道限速、雨天落石、司机轮换、停车、绕行备胎、导航离线
- **公共交通版**：枢纽换乘留白、当地打车/包车价格、景区观光车与索道替代方案、末班车
- 夜间出发必写夜路专项：疲劳高发点、隧道口明暗落差、雨夜标线

### 07 纯电专属 / 交通花费
- **纯电**：真实续航折算（别用标称）+ 逐日充电表 + 排队高峰对策 + 里程底线
- **油车**：百公里油耗 + 92/95 + 高速服务区加油排队 + ETC/收费
- **公共交通**：往返大交通票价 + 市内交通预算 + 包车一天价格
- 都要给"找桩/购票 App"

#### 纯电折算公式（写进正文，必须给算式）

```
真实高速续航 = 标称 CLTC × 电池健康度 × 高速折扣
              ≈ 470 × 0.9 × 0.6 = 254 km
雨天再打 0.92 → 233 km

每趟充电次数 = ceil( 单程里程 ÷ 真实续航 ) − 1
              = ceil(490 ÷ 254) − 1 = 2 次
```

**关键联动：折扣系数 → 充电次数 → 改写第 02 章时间轴、第 06 章路况、第 09 章电费。**
改了折扣，这三章的数字必须同步重算（电费约 17kWh/100km × 全程里程 × 1.5 元/kWh）。

排充电点的规矩：
- **到站表显 ≥25% 就该找桩**，不撑到 10%，更不撑到 0
- 中途**充到 90% 即可**（不是 100%），25–30 分钟；充满更慢且伤电池
- 充电点要**对应真实服务区**（写清在第几高速、第几公里、哪个区间），别写"途中随便充"
- 有雨预报的日子，**把第二个充电点往前挪**，给雨天留余量
- 酒店是否有桩要**让用户自己打电话确认**，并在 06 章写「若无桩，返程前一晚在商圈充到 100%」

### 08 一路吃什么
- 必点名 + 人均价格区间 + 点单公式（几人点几荤几素）
- 早餐/午餐/晚餐各一条当地特色
- 配 2 张实拍食物图

### 09 预算参考 · 人均分摊
- 表格：项目 / N 人合计 / 人均 / 说明
- **含人数与房间数**（如"4 人 2 间 × 6 晚"）
- 收尾给"省钱 N 招"

### 10 图库 & 笔记索引
- `.gal` 空容器即可，JS 自动克隆
- 表格 `@@NOTES@@`：序号 / 标题 / 赞 / 收藏 / 分享 / 「打开笔记 ↗」+「搜同款 ↗」
- 注明图片为 1080P 原图、未裁剪、版权归原作者

## 内联 SVG 地图（不加体积、能点开、离线可用）

用户要「带地理位置的地图」时，**不要引外部地图服务**（会破坏单文件自包含）。
正确做法：手写 **内联 `<svg>`**，矢量、几乎不占体积、离线可用、可被浏览器 DOM 校验。

### 套路

```html
<div class="mapbox">
  <svg viewBox="0 0 980 300" role="img" aria-label="路线示意图"> … </svg>
  <p class="mapnote">示意图，非按比例。</p>
</div>
```

```css
.mapbox{background:var(--card);border:1px solid var(--line);border-radius:18px;padding:14px 12px 8px;margin:6px 0 22px}
.mapbox svg{display:block;width:100%;height:auto}   /* 关键：宽度自适应，不写死 height */
.mapnote{font-size:12.8px;color:var(--muted);padding:4px 8px 8px;margin:0}
```

### 两张图的分工

| 图 | 放哪 | 画什么 |
|---|---|---|
| **路线图** | 01 章 | 起点→终点横向主干道；里程刻度、必经枢纽、**必充点（换色 + ⚡ + 到站表显%）**、省界虚线 |
| **城市点位图** | 04 章 | 地理要素（江/山/绿地）+ 编号圆点（①必去 ②弹性 ③住宿）+ 地铁线虚线 + 北箭头 + 图例 |

**坐标按里程/方位线性映射**，不要凭感觉摆：路线图 `x = 起点 + km/总里程 × 可用宽度`。

### 三个必须避开的坑

1. **SVG 里禁用 `<b>` / `<i>`** —— `validate.py` 的 `TAGS` 列表含 `b`、`i`，会在 SVG 里被计数成「未闭合标签」。
   要强调文字就用 `<tspan font-weight="700">` 或直接写 `<text font-weight="700">`。
2. **不要给 SVG 设固定 `height`** —— 写 `width:100%;height:auto`，否则窄屏横向溢出。
3. **文字不能越出 viewBox** —— 长标签容易跑出去。交付前用 DOM 逐个量：
   ```js
   Array.from(document.querySelectorAll('.mapbox svg text')).map(t => {
     const b = t.getBBox();
     return { txt: t.textContent, inside: b.x >= -1 && b.y >= -1 &&
              b.x + b.width <= vbW + 1 && b.y + b.height <= vbH + 1 };
   })
   ```
   越界数必须为 0。

### 诚实标注

示意图一律在 `.mapnote` 写明「非按比例，仅表达相对方位与动线，实际导航以高德/百度为准」。

## 左侧二级目录规范（仅电脑版，强制）

`assets/template-desktop.html` 里那张 `.toc` 顶部目录盒**只在 <1280px 显示**；宽屏由
`scripts/sidebar.py` 生成的左侧固定侧栏接管。两者不要同时手写。

### 怎么生成

```bash
python scripts/sidebar.py 川藏线24天攻略-电脑版.html --title "川藏线 24 天 · 目录"
```

脚本**幂等**：重复运行会替换旧侧栏，不会叠加。写完正文就跑一次，跑完不要再手改 `#side`。

> 注入的 CSS / JS 都被 `/* SIDEBAR:CSS:BEGIN|END */`、`/* SIDEBAR:JS:BEGIN|END */` 哨兵注释包起来。
> **改脚本时不要用「猜下一个选择器」的方式删除旧块** —— 注入块里含 `@media`、`section` 这类选择器，
> 猜测式正则会在中途截断，只删掉前半段，残渣每次跑都累积一份（实测连跑 5 次涨 834 字节）。
> 必须按哨兵整块删。改完请连跑 5 次验证字节数完全不变。

### 二级目录怎么声明（不要手写锚点 id）

在正文元素上加 `data-toc` 属性，脚本按文档顺序自动归到所属章节：

```html
<div class="day" data-toc="D0–D5 康定 · 折多山 · 亚丁">   <!-- 二级文案取属性值 -->
<h4 class="mini" data-toc>抢票日历</h4>                   <!-- 二级文案自动取标题文字 -->
<div class="gal" id="gal" data-toc="实拍图库"></div>       <!-- 已有 id 的沿用原 id -->
```

- 元素**没有** id → 自动补 `toc-1`、`toc-2`…
- 元素**已有** id（如 `#gal`，页内 JS 依赖）→ 沿用，**不要删**
- 挂在外层容器上（如整组 `.day` 卡片挂一个 `data-toc`），不要挂到每一个卡片里

### 分级与断点

| 项 | 规则 |
|---|---|
| 层级 | **最多两级**。一级 = `<section id="sN">`，二级 = 该章内的 `data-toc`。`data-toc` 只挂在章节内元素上，天然不会产生第三级 |
| 每章二级项 | 建议 2–5 个；超过 12 个脚本会 `WARN`，应合并 |
| 显示断点 | **≥1280px** 显示侧栏（`body` 自动 `padding-left:252px`，`.toc` 自动隐藏）；<1280px 反之，侧栏隐藏、回到顶部目录盒 |
| 高亮 | 一级与二级**同时**高亮；二级只在滚动进入该二级项区间（target 顶部在当前章 top+2 ~ 130px）时才亮 |
| 进度条 | 侧栏底部 `.side-bar > #sidefill`，宽度 = 已滚动比例 |

### 为什么用原生锚点而不是 JS 平滑滚动

侧栏链接**不劫持 click、不用 smooth 动画**，靠浏览器原生锚点 + CSS `scroll-margin-top:18px`。
两个理由：① 禁用 JS 时链接依然可用，进度/高亮只是增强；② 手写 `scrollIntoView({behavior:'smooth'})`
会和滚动高亮的 `getBoundingClientRect()` 判定打架，出现「高亮停在上一节」。

`hashchange` 要额外监听一次并重跑高亮函数——从地址栏直接跳到 `#s7` 时不触发 `scroll`。

### 交付前必测

```js
// 1. 结构：一级 10 / 二级 N / 三级必须 0
[document.querySelectorAll('#side :scope > ol > li').length,
 document.querySelectorAll('#side :scope > ol > li > ol > li').length,
 document.querySelectorAll('#side ol ol ol').length]   // → [10, 31, 0]

// 2. 失效锚点必须 0（每个 href 都要有对应元素）
[...document.querySelectorAll('#side a')]
  .filter(a => !document.getElementById(a.getAttribute('href').slice(1))).length

// 3. 侧栏内部不横向溢出
side.scrollWidth - side.clientWidth    // → 0

// 4. 点击跳转后 target 顶部应等于 scroll-margin-top（≈18），不是被侧栏挡住也不是 0
```

⚠️ **测宽屏必须把 `min-width` 和 `max-width` 一起下调**（临时副本改成 900px / 899px），
只改 `min-width` 会出现「正文已让位 252px 但侧栏被隐藏」的空洞，看起来像布局坏了。

## 校验陷阱（写页面时就要避开，别等 WARN）

| 现象 | 原因 | 处理 |
|---|---|---|
| `WARN 索引表 N 行 vs 正文用图 M 张` | `validate.py` 用 `<tr><td class="num">` 计数，**正文手写表格首列也带 `num`** 会被算进去 | 手写表格首列**不要**加 `class="num"`；数字列照常用 |
| 同一 data URI 内嵌两次 | 同一张图在正文出现多次 | 每个 `@@IMG:key@@` 只用一次；图库由 JS 克隆，不要手写 |
| build 后体积翻倍 | 同上 | 同上 |
| 替换图片后变成两张 | 只匹配了 `<img>` 的 `alt=` 部分 | **替换必须匹配完整 `<img ...>` 标签** |
| 删包裹层后标签不闭合 | 只删了 `<div class="g2">` 开头 | 连 `</div>` 一起删 |

## 写作纪律

- 每个数字都要有来源；查不到就写"参考价，以现场公示为准"
- 不确定的路况/营业时间，别写成确定事实
- 价格统一标"成人价"，团队票/儿童票单列
- 时间表用 24 小时制，长途日每 2 小时必须出现一次休息/换手点
- **同一份数据只留一个权威出处**：Hero 区统计数字、第 09 章预算合计、正文小计三处必须对得上
  （改一处要同步全部；`1,790` vs `7,632÷4 = 1,908` 这类不一致必须消除）
